# Citizen Report

Citizen Report is a web application I built to make it easier for people to report issues happening in their community.

The idea behind the project is simple: people often notice problems around them , such as damaged roads, flooding, waste disposal issues, broken public facilities, or other community concerns but may not know the right place to report them. Citizen Report provides a simple platform where these issues can be submitted and documented.

## What the Project Does

Users can submit reports about issues in their community by providing information about the problem. The platform is designed to keep the reporting process simple and easy to understand.

The goal was to create something practical while also improving my skills in building responsive and user-friendly web applications.

## Features

- Submit community issue reports
- View submitted reports
- Categorize different types of issues
- Simple and responsive user interface
- Form validation
- Easy navigation across the application
- Works across desktop and mobile screen sizes

## Built With

- Next.js
- React
- TypeScript
- CSS
- Git & GitHub

## Why I Built It

I wanted to work on a project that solves a real-world problem rather than building something purely for demonstration.

Citizen Report gave me the opportunity to think about how technology can make communication between people and their communities easier, while also allowing me to practise building reusable components, handling forms, organizing a frontend project, and creating a clean user experience.

## Project Status

The project is currently part of my web development portfolio and may continue to receive improvements and new features.
